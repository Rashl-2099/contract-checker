## 📌 نبذة عن المشروع
منصة ذكاء اصطناعي مؤسسية متكاملة لفحص وتدقيق العقود القانونية وفق الأنظمة المعتمدة، مع استخراج البيانات الجوهرية، ورصد الفخاخ التعاقدية (Killer Clauses)، ومحاكاة التفاوض الآلي بين وكلاء أذكياء (Multi-Agent System)، وأرشفة الفحوصات في قاعدة بيانات SQLite.

### تصنيفات العقود المدعومة
| التصنيف | أبرز ما يتم فحصه |
|---|---|
| عقد شركات / تجاري وتوريد (B2B) | غرامات التأخير، سقف المسؤولية، السرية، الإنهاء، الملكية الفكرية، القوة القاهرة |
| عقد عمل (أفراد ومنشآت) | فترة التجربة (م53)، ساعات العمل (م98)، الإجازة (م109)، نهاية الخدمة (م84)، عدم المنافسة (م83) |
| عقد إيجار عقاري | زيادة الأجرة، مبلغ الضمان، الصيانة، الفسخ والإخلاء، التجديد |
| عقد خدمات تقنية / SaaS | مستوى الخدمة SLA، حماية البيانات الشخصية، ملكية البيانات، تعديل الأسعار |
| اتفاقية عدم إفصاح (NDA) | تعريف المعلومات السرية، مدة الالتزام، التعويض الاتفاقي، عدم الاستقطاب |

### المزايا
* 📊 مؤشرات فورية: مؤشر السلامة القانونية، البنود غير المتوازنة، المخاطر الحرجة، الفخاخ المرصودة.
* 📌 بطاقة البيانات الجوهرية: الأطراف، المدة، المقابل المالي، التجديد والإنهاء.
* 🚨 رادار الفخاخ التعاقدية مع تصنيف الخطورة.
* 🔍 فحص كل بند: النص المقتبس، التحليل، السند النظامي، والصياغة البديلة المقترحة.
* 🤝 محاكي تفاوض آلي بين وكيلين ينتهي بصياغة توافقية (Win-Win).
* 🗄️ سجل فحوصات في SQLite مع إمكانية إعادة فتح أي فحص سابق أو حذفه.
* 📄 تصدير مذكرة الفحص القانوني (Markdown) وبيانات الفحص (JSON).
* 📥 ثلاث طرق للإدخال: نموذج تجريبي جاهز، رفع ملف PDF، أو لصق نص العقد.
* 🌐 واجهة ثنائية اللغة (العربية / English) مع تبديل فوري للاتجاه (RTL / LTR).

### 🌐 دعم اللغتين (Arabic / English)
* مبدّل اللغة أعلى الصفحة، ويمكن فتح المنصة مباشرة بالإنجليزية عبر الرابط `?lang=en`.
* تُكتب نتائج التحليل والمذكرة ومحاضر التفاوض بلغة الواجهة المختارة.
* المحركان يقرآن العقود العربية والإنجليزية، ولكل تصنيف عقد تجريبي باللغتين يحتوي على الفخاخ نفسها.
* عند تبديل اللغة بعد الفحص بالمحرك المحلي يُعاد التقرير فوراً باللغة الجديدة؛ أما تقارير نموذج اللغة فتبقى بلغتها مع تنبيه لإعادة الفحص.

> **English:** The platform is fully bilingual. Use the switch at the top of the page (or open it with `?lang=en`). The interface, analysis results, legal memo and negotiation transcripts follow the selected language, and both engines can read Arabic and English contracts.

## 🏗️ معمارية النظام (System Architecture)
* `app.py`: واجهة المستخدم التفاعلية ولوحة التحكم المبنية بـ Streamlit (عربي RTL / إنجليزي LTR).
* `i18n.py`: نصوص الواجهة باللغتين وترجمة القيم الثابتة (الحالات، مستويات الخطورة، الأبعاد) عند العرض.
* `compliance_engine.py`: خط معالجة واستدلال LangChain (LCEL) المقيد بهياكل Pydantic عبر `with_structured_output`، مع موزّع ذكي يرجع للمحرك المحلي عند الحاجة.
* `rules_engine.py`: **المحرك المحلي للخبير القانوني** — يحلل العقد دون إنترنت أو مفتاح API ويُنتج نفس هيكل التقرير، ليبقى النظام عاملاً دائماً.
* `negotiator.py`: نظام الوكلاء المتعددين (Multi-Agent Negotiation) عبر LangChain، مع قوالب تفاوض خبيرة احتياطية.
* `schemas.py`: هياكل البيانات المشتركة (Pydantic) ومعادلة مؤشر السلامة الموحدة.
* `database.py`: وحدة إدارة قاعدة بيانات SQLite لتخزين سجل الفحوصات والتقارير الكاملة.
* `report_export.py`: توليد مذكرة الفحص القانوني.
* `labor_law_data.py`: القواعد المعرفية المرجعية للأنظمة واللوائح لكل تصنيف.
* `demo_contracts.py`: نماذج عقود تجريبية تحتوي عمداً على فخاخ ومخالفات للاختبار.

### محركات التحليل
| الخيار في الشريط الجانبي | السلوك |
|---|---|
| تلقائي (افتراضي) | يستخدم LangChain + OpenAI إذا وُجد مفتاح صالح، وإلا المحرك المحلي |
| LangChain + OpenAI فقط | يستخدم نموذج اللغة، ويرجع للمحرك المحلي مع تنبيه عند تعذر الاتصال |
| المحرك المحلي | تحليل فوري دون إنترنت ودون تكلفة |

> مؤشر السلامة يُحسب بمعادلة موحدة للمحركين: متوافق = 1، غير مذكور = 0.5، مبهم/عالي المخاطر = 0.4، مخالف = 0.

## 🚀 طريقة التثبيت والتشغيل المحلي

1. **تجهيز البيئة الافتراضية:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```
2. **تثبيت المتطلبات:**
   ```bash
   pip install -r requirements.txt
   ```
3. **إعداد مفتاح OpenAI (اختياري):** انسخ `.env.example` إلى `.env` وضع المفتاح:
   ```
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=gpt-4o-mini
   ```
   بدون مفتاح تعمل المنصة كاملة عبر المحرك المحلي.
4. **تشغيل المنصة:**
   ```bash
   streamlit run app.py
   ```
